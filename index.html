Help & guidance

A practical guide to loading data, building charts, interpreting SPC signals, and saving your work.

1. What this tool does

This tool helps you create Statistical Process Control (SPC) charts directly in your browser. All calculations happen locally in your browser. Your data are not uploaded to a server.

It is designed for learning, improvement work, service monitoring, and rapid analysis. It is not intended to replace a regulated statistical package.

  • Run charts – values over time with a median line and simple run/trend rules.
  • XmR charts – Individuals (X) chart with mean and control limits plus an optional Moving Range (MR) chart.
  • X̄–S charts – for grouped continuous data with multiple observations per subgroup.
  • P / U charts – for proportions or rates.
  • T / G charts – for rare events.
2. Quick start
  1. Load data using CSV, Excel, or the Data editor.
  2. Select the chart type and choose the relevant columns.
  3. Click Generate / Recalculate if the chart does not update automatically.
  4. Add titles, labels, targets, splits, or annotations if needed.
  5. Review the summary text and chart signals.
  6. Save the chart if you want to return to it later.
3. Preparing and loading your data

Your data usually need at least:

  • a time or order column (for example month, week, date, or sequence)
  • a value column (the measure you want to plot)
You can now load data in three ways:
  • Upload a CSV file
  • Upload an Excel workbook (.xlsx or .xls)
  • Paste or edit data directly in the Data editor

If you upload an Excel workbook, the tool opens the Data editor so you can inspect the worksheet before importing it. You can switch between worksheets, trim unwanted rows or columns, and then click Apply data.

The tool tries to suggest sensible X and Y columns automatically, but you can change them yourself at any time.

If your date column uses numeric dates such as 01/02/2024, use the Date format for numeric dates setting so the tool interprets them correctly.

Default: UK day-first (dd/mm/yyyy).

4. Using the Data editor

The Data editor is useful when:

  • you want to paste data from Excel
  • your Excel workbook contains multiple sheets
  • your worksheet contains extra rows or columns that need trimming
  • Use the Worksheet selector to switch between sheets in an uploaded Excel file.
  • Tick or untick First row contains headers depending on whether the top row is headings or data.
  • Use Auto-detect as a quick suggestion, but always sense-check it.
  • Right-click a row number to delete or insert rows.
  • Right-click a column heading to delete or insert columns.
  • You can select multiple rows or columns before deleting them.

Tip: the Data editor lets you clean a worksheet inside the tool before applying it to the chart.

5. X-axis type and chart type

Choose the chart type that matches the kind of data you have:

  • Run chart – a simple starting point for values over time.
  • XmR chart – one continuous observation per time point.
  • X̄–S chart – grouped continuous measurements with several values per subgroup.
  • P chart – proportions with numerator and denominator.
  • U chart – rates with changing opportunity.
  • T / G charts – rare events.

If you are unsure, use the Help me choose a chart option.

6. Baseline, splits, targets and annotations
  • Baseline lets you calculate the initial centre line and limits using an earlier reference period.
  • Splits let you recalculate the centre line and limits from a chosen point onward.
  • Targets show the level you want to achieve, but they are not the same as control limits.
  • Annotations let you mark events that may help explain a change in the pattern.

In general:

  • use a baseline to compare against an earlier period
  • use a split when a later period should be treated as a new system
7. Interpreting the summary

The summary underneath the chart helps explain what the tool has found.

  • Common-cause variation means the process looks stable within its current level of performance.
  • Special-cause variation means the pattern suggests something may have changed.
  • A process can be stable but still poor if the level of performance is consistently below what you need.

Look for sustained changes, not just one good or bad point. Use local knowledge to interpret what was happening at that time.

8. Saving and reopening your work

You can now save the whole chart as a json file.

  • Save chart stores the current data and chart settings together in one .json file.
  • Open saved chart restores that saved chart so you can continue working on it later.

Chart json files can preserve things like:

  • selected columns
  • chart type
  • titles and labels
  • rules and targets
  • splits and annotations
9. Copying and downloading charts
  • Right clicking on the chart brings up the menu that allows you to export the chart as an image.
  • Use the chart options to adjust appearance before exporting.
  • You can also copy the chart(s) and/or analysis to your clipboard for easy pasting into a report or presentation.
  • Use the show/hide MR/S chart toggle in the Chart tab to toggle whether that is included in your ouput
10. Data privacy

The tool runs entirely in your browser:

  • data are not sent to a server
  • uploaded files are processed locally in your browser session
  • once you close or refresh the page, unsaved work is no longer retained unless you saved a chart json file

Always follow your local information governance guidance before using real patient-identifiable data.
