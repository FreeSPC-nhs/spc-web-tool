Help & guidance

A practical guide to loading data, building charts, interpreting SPC signals, and saving your work.

1. What this tool does

SimpleSPC is a free, browser-based tool for creating Statistical Process Control (SPC) charts and Pareto charts.

It helps you understand patterns in data, distinguish routine variation from signals of change, and identify opportunities for improvement. All calculations take place locally in your browser. Your data are not uploaded to a server.

SimpleSPC is designed for learning, quality improvement, service monitoring and practical analysis. It is not intended to replace a regulated statistical package.

Available charts:

  • Run chart – shows values in time or sequence order, using a median and simple rules to identify non-random patterns.
  • XmR chart – shows individual measurements with a mean and control limits, alongside an optional moving-range chart.
  • X̄–S chart – examines averages and variation within groups of continuous measurements.
  • C chart – monitors counts of events or defects when the opportunity for events is reasonably constant.
  • P and Laney P′ charts – monitor proportions, such as the percentage of patients experiencing an event. P′ adjusts control limits when observed variation differs from that expected by a standard P chart.
  • U and Laney U′ charts – monitor event rates when the number of opportunities varies. U′ adjusts control limits when observed variation differs from that expected by a standard U chart.
  • T chart – monitors the time between rare events.
  • G chart – monitors the number of opportunities between rare events.
  • Pareto chart – ranks categories from most to least frequent to help prioritise investigation and improvement.

Important: Pareto charts are different from time-ordered SPC charts. They help identify which categories account for the most occurrences, but do not establish whether a process is stable or whether a change is statistically significant.

2. Quick start
  1. Load data using CSV, Excel, or the Data editor.
  2. Select the chart type and choose the relevant columns.
  3. Click Generate / Recalculate if the chart does not update automatically.
  4. Add titles, labels, targets, splits, or annotations if needed.
  5. Review the summary text and chart signals.
  6. Save the chart if you want to return to it later.
3. Preparing and loading your data

The columns you need depend on the chart type. Most SPC charts need a time or sequence column and a measurement or count.

  • P, P′, U and U′ charts also need a denominator or opportunities column.
  • X̄–S charts need a subgroup identifier and individual measurement values.
  • Pareto charts need a category column, with an optional frequency/count column if your data are already summarised.
You can now load data in three ways:
  • Upload a CSV file
  • Upload an Excel workbook (.xlsx or .xls)
  • Paste or edit data directly in the Data editor

If you upload an Excel workbook, the tool opens the Data editor so you can inspect the worksheet before importing it. You can switch between worksheets, trim unwanted rows or columns, and then click Apply data .

The tool tries to suggest sensible X and Y columns automatically, but you can change them yourself at any time.

If your date column uses numeric dates such as 01/02/2024, use the Date format for numeric dates setting so the tool interprets them correctly.

Default: UK day-first (dd/mm/yyyy) .

4. Using the Data editor

The Data editor is useful when:

  • you want to paste data from Excel
  • your Excel workbook contains multiple sheets
  • your worksheet contains extra rows or columns that need trimming
  • Use the Worksheet selector to switch between sheets in an uploaded Excel file.
  • Tick or untick First row contains headers depending on whether the top row is headings or data.
  • Use Auto-detect as a quick suggestion, but always sense-check it.
  • Right-click a row number to delete or insert rows.
  • Right-click a column heading to delete or insert columns.
  • You can select multiple rows or columns before deleting them.

Tip: the Data editor lets you clean a worksheet inside the tool before applying it to the chart.

5. X-axis type and chart type

Choose the chart type that matches the kind of data you have. The main options are:

  • Run chart – a simple starting point for values over time.
  • XmR chart – individual continuous measurements, with control limits.
  • X̄–S chart – continuous measurements collected in subgroups.
  • C chart – counts where the opportunity for events is reasonably constant.
  • P and Laney P′ charts – proportions, using a numerator and denominator. P′ adjusts for greater or smaller variation than expected.
  • U and Laney U′ charts – event rates with changing opportunities. U′ adjusts for greater or smaller variation than expected.
  • T and G charts – time or opportunities between rare events.
  • Pareto chart – ranks categories from most to least frequent to help prioritise investigation.

X-axis type:

  • Date / time – use when observations have dates or times and you want to display them chronologically.
  • Sequence / category – use when observations should be shown in order without treating their labels as dates.

Pareto charts use categories rather than dates. Categories are ranked by frequency, with a cumulative percentage line. They are not time-ordered SPC charts and do not have statistical control limits.

If you are unsure which chart to use, click Help me choose. You can also use Chart setup for guidance on the data columns required by the selected chart.

6. Baselines, splits, targets and the right-click menu

SimpleSPC offers additional features to help you investigate and explain your data.

  • Set a baseline: Open the Baseline tab and enter the number of initial points you want to use as a reference period. Leave this blank if you do not need a separate initial baseline.
  • Set a target: Open the Baseline tab and find Target. Enter the level of performance you want to achieve, then select whether values at or above, or at or below, that target are good. You can also show or hide the target line. A target is a performance goal, not a statistical control limit.
  • Add a split: Right-click a plotted point and choose Splits, then Add split after this point . This divides the chart into separate analysis periods where supported.
  • Add an annotation: Right-click a plotted point and use the Annotations menu to record an event, intervention or explanation.

Discover the right-click menu

Right-click directly on a chart to discover additional options. Available actions depend on the chart type and where you click.

  • Add, edit or delete annotations.
  • Add or remove split periods.
  • Exclude or reinclude investigated observations from control-limit calculations.
  • Show, hide or restore centre-line labels.
  • Copy the chart, copy its analysis, or export an image.

Important – excluding data points: Only exclude an observation from limit calculations after investigating and understanding the reason it differs, and deciding it does not represent routine process variation. Excluded observations remain visible and can be reincluded. Consider annotating the reason for exclusion.

On X̄–S charts, exclusion applies to an entire subgroup. Pareto charts do not use control-limit splits or point exclusions.

Similarly, only use a split when there is good reason to believe the process has changed. Splits should reflect investigated changes, not simply remove inconvenient signals.

Look for the small ? symbols beside controls throughout SimpleSPC. Hover over them, or focus them with the keyboard, for additional guidance. You can also ask the SPC helper about your chart and its interpretation.

7. Interpreting the summary

The summary underneath the chart helps explain what the tool has found.

  • Common-cause variation means the process looks stable within its current level of performance.
  • Special-cause variation means the pattern suggests something may have changed.
  • A process can be stable but still poor if the level of performance is consistently below what you need.

Look for sustained changes, not just one good or bad point. Use local knowledge to interpret what was happening at that time.

8. Saving and reopening your work

You can save your work in different ways, depending on how you want to use it later.

  • Save chart stores the current data and chart settings together in a .json project file.
  • Open saved chart restores a previously saved project file so you can continue working on it later.
  • Save portable chart creates a self-contained .html file containing the SPC tool, your data and your chart settings. The saved file can be opened directly in a web browser and used again without an internet connection.

Saved charts can preserve things such as:

  • the underlying chart data
  • selected columns and X-axis type
  • chart type
  • titles, labels and axis settings
  • rules and targets
  • baseline settings
  • splits and annotations

A portable HTML file remains editable. After opening it, you can change the data or chart settings and use Save portable chart again to create an updated copy.

Important: Both JSON project files and portable HTML files contain the data used to create the chart. Store and share saved files in line with your organisation's information-governance, confidentiality and cybersecurity requirements.

9. Copying and downloading charts
  • Right-click the chart to open the menu for exporting the chart as an image.
  • Use the chart options to adjust the chart's appearance before exporting.
  • You can copy the chart(s) and/or analysis to your clipboard for easy pasting into a report, presentation or document.
  • Use the Show/hide MR/S chart option in the Chart tab to control whether the secondary chart is included in copied or downloaded output.
10. Data privacy

The tool runs entirely in your browser:

  • data are not sent to a server
  • uploaded files are processed locally in your browser session
  • Unsaved work may be lost when you close or refresh the page. Use Save chart (JSON) or Save portable chart (HTML) to keep a copy of your work.

Important: SimpleSPC is not designed for patient-identifiable or other sensitive personal data. Use anonymised or appropriately aggregated data, and follow your organisation's information-governance, confidentiality and cybersecurity requirements. Remember that saved JSON and portable HTML files contain the data used to create the chart.
