Help & guidance

This section explains how to use the Simple SPC Web Tool and how to interpret the charts.

1. What this tool does

This tool helps you create Statistical Process Control (SPC) charts directly in your browser. All calculations happen in your browser. The data are not uploaded to a server. This tool has been designed for learning, improvement work, and rapid analysis — not as a regulated statistical package. It supports:

  • Run charts – values over time with a median line and simple run/trend rules.
  • XmR charts – Individuals (X) chart with mean and control limits plus a Moving Range (MR) chart.
  • X̄–S charts – X̄ and S charts for grouped data (multiple measurements per subgroup).
  • P / U charts – for proportions or rates.
  • T / G charts – for rare events.

The control panel on the left side of the screen allows you to upload data, select options for how to present it, and use some advanced options for refining your charts.

2. Preparing and loading your data
  • Your data should have at least two columns:
    • a time/order column (e.g. date, month, or sequence number), and
    • a numeric column (e.g. waiting time, rate, count, score).
  • Click “Upload CSV file” to choose a .csv file, or use the “Open data editor (paste/type data)” button to paste directly from Excel.
  • Once loaded, use the “Choose columns” dropdowns to specify:
    • Date / X-axis column
    • Value / Y-axis column

If the chart does not appear, check that the value column contains valid numbers and that there are no unexpected headers or blank rows in the middle of the data.

3. X-axis type & chart type

X-axis type

  • Date / time – recommended for usual time-series SPC (e.g. daily, weekly or monthly measures).
  • Sequence / category – use when you want each row in the order it appears (e.g. individual patients, samples or tests), even if the X-value is not a date.

Chart type

The tool supports several SPC chart types. If you are unsure which to use, click “Help me choose a chart” to open the chart selection wizard.

  • Run chart
    • Simple view of data over time using the median.
    • Useful as a first look or when data are limited.
  • XmR chart
    • For continuous data with one observation per time point.
    • Shows a mean with upper and lower control limits.
    • Includes an optional Moving Range (MR) chart.
  • X̄–S chart
    • Confirming and understanding variation within and between subgroups.
    • Use when you have multiple measurements per subgroup (e.g. samples per day).
  • P chart
    • For proportions (e.g. percentage of patients with a defect).
    • Requires a numerator and denominator.
  • U chart
    • For rates (e.g. defects per opportunity).
    • Requires a count and a number of opportunities.
  • T chart
    • For time between rare events.
  • G chart
    • For opportunities between rare events.

If you are new to SPC, start with a Run chart or XmR chart unless the wizard suggests otherwise.

4. Baseline, splits and target

Baseline

The “Use first N points as baseline” box lets you restrict which points are used to calculate the median (run chart) or mean and limits (XmR). Leave this blank to use all points.

Splitting control limits

Splits allow you to recalculate the mean and control limits from a chosen point onwards. This is useful when you make a clear change to the system (for example, introducing a new pathway) and want to assess performance after that change.

Splits are added from the chart menu by right-clicking on the chart.

Use splits sparingly and only when there is good evidence of a real process change. Avoid using splits simply to make a chart appear more stable.

Target / goal

You can enter a Target / goal value and choose whether “at or above” or “at or below” the target is desirable. The chart will show a dashed target line.

In XmR mode, the summary panel will show an approximate process capability against this target if the process looks stable (no obvious special-cause signals).

5. Annotations

Annotations are used to mark important events, such as new interventions, policy changes or data definition changes.

Annotations are added from the chart menu by right-clicking on the chart.

Keep annotation labels short and factual to avoid cluttering the chart.

6. Interpreting the summary

Under the chart, the Summary section gives a brief interpretation of the pattern, tailored to the selected chart type.

Depending on the chart, it may comment on:

  • The number of data points and which points are used as the baseline.
  • The median (run chart), mean and limits (XmR / X̄–S), or centre line appropriate to the chart type.
  • Possible special-cause signals such as:
    • points beyond control limits,
    • long runs on one side of the centre line,
    • clear upward or downward trends.

These rules are intended as prompts, not absolute answers. Always interpret the pattern in the context of the clinical or operational system.

7. Glossary
  • Centre line – indicates the “usual” level of performance the data (using the mean/average or median).
  • Control limits - Upper (UCL) & Lower(LCL) – statistical boundaries, calculated from historical data, that estimate the range of routine (common-cause) variation.
  • Common-cause variation – normal, expected ups and downs when the system hasn’t fundamentally changed. This represents the range of variability that you might expect from everyday factors that are inherent in the process/system.
  • Special-cause signal – a pattern that’s unlikely to be routine variation alone (for example, a point beyond limits or a sustained run). This is usually indicative of something 'unusual' happening. Usually requires investigation to understand the cause.
  • Baseline – a subset of data points that can be used to calculate and 'fix' the centre line and limits. Setting a baseline is useful when you have implemented a change and want to test whether it has had an effect on 'normal' performance.
  • Run/SPC rules – a statistically significant pattern rule (e.g. many points in a row on one side of the centre line) used to identify special cause variation.
  • Shift – an indication of a sustained change in performance that is significantly different to previous performance. If the cause of the change is understood (e.g. it was as a result of improvement work), and it is likely to continue to affect ongoing performance then might trigger a split in calculation of control limits.
  • Split – recalculation of the centre line and control limits at a specific point in time. Usually triggered by a sustained shift in performance.
  • Trend – several points increasing or decreasing in a row, suggesting a directional change.

If you’re unsure, treat the rules as prompts and combine them with local knowledge. If decisions are high-stakes, consider specialist statistical support.

8. Copying and downloading charts

Additional options are available from the chart menu by right-clicking on the chart.

  • Copy chart image – copies the chart to the clipboard for pasting into slides, emails or documents.
  • Copy chart and analysis – copies the chart together with the summary text.
  • Save chart as PNG – downloads the chart image to your computer.
  • Download PDF report – exports the chart and summary into a simple PDF layout.

When copying or exporting charts, make sure axes labels, annotations and context are clear to someone who was not involved in the analysis.

9. Saving and reusing chart settings (optional)

You can save your chart settings so you can quickly recreate the same chart layout later. This is useful if you update the same chart regularly (for example, weekly or monthly reporting).

  • Export settings saves a small .json file containing your chart choices (such as chart type, selected columns, baseline, rules, targets, labels, splits and annotations).
  • Import settings reloads a previously saved settings file and reapplies those choices to the tool.

Important: the settings file does not include your data. You still need to load your data as usual — either by uploading a CSV file or by pasting data from Excel into the data editor.

It doesn’t matter how the data is loaded: as long as the column names match, the saved settings will be applied in the same way. If your data has different column names, the tool may not be able to reselect everything automatically. If this happens, you’ll be prompted to choose the correct columns.

10. Data privacy

The tool runs entirely in your browser:

  • Data are not sent to a server.
  • Once you close the page, your data are no longer available to the tool.

Always follow your local information governance guidance before using real patient-identifiable data.
